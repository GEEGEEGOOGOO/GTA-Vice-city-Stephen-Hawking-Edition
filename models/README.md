# Blender models

Unzip the Blender model download and keep its **Blender Models** folder together. Open the `.blend` files in Blender 5.2.2 LTS. Project files include earlier revisions and game-specific exports.

| Project | Start with |
| --- | --- |
| Stephen Hawking | `Stephen Hawking/Stephen Hawking.blend` |
| Ambassador | `Ambassador/ambassador_car.blend` or `Ambassador/Exterior revisions/Ambassador_Realistic_Glazing.blend` |
| Autorickshaw | `Autorickshaw/autorickshaw_front_window_corrected.blend` or `Autorickshaw/autorickshaw_gta_ready.blend` |
| Bicycle | `Bicycle/roadster_bicycle.blend` |
| Haryana bus and Tata truck | `Haryana Bus/haryana_roadways_bus.blend` and `Tata Truck/tata_painted_truck.blend` |
| Game-ready bus and truck | `Commercial Traffic/output/bus.blend` and `Commercial Traffic/output/yankee.blend` |
| Tumbler | `Tumbler/model/Tumbler_Exact_Game_Animated.blend` |
| Vehicle pack | The seven models in `Vehicle Pack/output` |
| BYD, Citroën, Hyundai, Maruti and Mahindra projects | `Cars/Blender` |
| Footpaths, in-game props and animation | The `Footpaths`, `Game Props`, and `Kamehameha` folders |

The optional wheelchair-drive add-on sits beside the Hawking scene. Install it from disk in Blender's Add-ons preferences, then use the **Wheelchair** panel in the 3D View sidebar.

The two historical Fortuner scenes under `Vehicle Pack/toyota-fortuner-2021` still reference nine missing source textures. The final game-ready Fortuner scene is `Vehicle Pack/output/landstal.blend`, with its available textures included.
